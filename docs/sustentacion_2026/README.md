## Regenerar la guía de 101 páginas

La fuente HTML se renderiza con Chrome/Playwright a A4, 15 mm de margen, escala 1.02 y pie “Página X de Y”. Debe salir exactamente en **101 páginas**. Si cambia el número, se ajusta el contenido, no el pie. El PDF resultante se sube a Drive; no se versiona en Git.

> Un parche manual del PDF ya produjo un pie de página incorrecto (“Página 100 de 101” en la página 84). Por eso la regla es re-renderizar desde la fuente, nunca editar el PDF a mano.

## Regla

No duplicar estos archivos en el Escritorio. Si se necesita una copia local para leer, se descarga de Drive y se borra al terminar.
